# Анти-ИИ Квен Академия — Тренажёр по истории России и законодательству РФ

Бесплатный офлайн-тренажёр для подготовки к экзамену с целью приобретения
гражданства Российской Федерации. Полностью соответствует спецификации
КИМ ФИПИ 2026 года.

## Возможности
- 36 заданий в каждом варианте (18 по истории России + 18 по основам законодательства РФ)
- 4 варианта (A–D) для полноценной тренировки
- 40 первичных баллов, порог сдачи — 28 (история ≥ 12, законодательство ≥ 12)
- Три режима работы: 🎓 Тренировка, 📝 Экзамен, 🔁 Работа над ошибками
- Таймер на 90 минут с предупреждающими состояниями
- Интерфейс на русском и английском языках
- Тёмная и светлая темы оформления
- Развёрнутые задания (11, 18, 33) с эталонными ответами
- Версия для печати, экспорт результатов в .txt
- Без рекламы, без трекинга, без регистрации — всё работает прямо в браузере

## Структура заданий
| Блок | Задания | Максимум баллов |
|------|---------|-----------------|
| История России | 1–18 | 20 |
| Основы законодательства РФ | 19–36 | 20 |
| **Итого** | **36** | **40** |
